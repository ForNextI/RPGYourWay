# RPG Your Way 1.9.0

Play readability and color-balance pass.

- Adds modest breathing room between **Roll Your Dice Here** and the Purist / Story first control, and between **Characters** and the first character card.
- Changes the Play campaign topbar from pale olive to the same warm tan/cream treatment used by the export and story-direction help buttons.
- Changes character-card faces from pale olive to the site's light cream surface.
- Changes **Session tools** to a forest-green face with white serif text and increases its label size for readability.
- Changes **Latest turn** to the same warm light surface used by the adjacent help controls.
- Changes the landing-page action from **Start New Campaign** to **Start A New Campaign**.
- Advances the application release line from 1.8.12 to **1.9.0**.
