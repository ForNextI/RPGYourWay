# RPG Your Way 1.11.7

Start controls and destructive-action polish.

- Adds space below **Character import help** so the next Start content does not crowd the help control.
- Renames the three character-choice settings to **Character backstory usage**, **Inter-party romance**, and **Character secret reveals**.
- Replaces the browser-native number dropdowns used in Start questions 2 and 3 with RPG Your Way number pickers: forest numbers at rest and lime hover/focus furniture instead of the operating system's white/blue popup treatment.
- Moves **Remove this character** to the upper-right of the character record beside the close control.
- Requires a second click on **Are you sure?** before a character is removed from the active party.
- Adds an **Are you sure?** step on the Account page before opening the existing typed-DELETE account-deletion confirmation.
- Advances the release from **1.11.6** to **1.11.7**.
