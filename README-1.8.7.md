# RPG Your Way 1.8.7

Build 1.8.7 turns the rebuilt Start page from a UI prototype into a functioning onboarding path. Custom characters are added first and then imported into RPG Your Way one at a time through the restored AI character-intake engine, with required and recommended clarification tiers. Ordinary imports remain included; unusually large or complex imports require explicit permission before using account balance. Start Page Help is connected with a 25-question session allowance. Onward now creates the browser campaign and opens Play. The character file control accepts both click-to-browse and drag/drop, the universal name/portrait editing note is added, Contact returns to ordinary footer-link styling, and the header compass mark is recentered in a roomier brass square.
