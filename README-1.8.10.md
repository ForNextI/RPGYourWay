# RPG Your Way 1.8.10

Start-page AI conversations now behave like conversations instead of replacing text above the input.

- Character-import clarifications keep a visible user/AI dialogue, with required and recommended ambiguities still clearly separated.
- Clarification replies are read aloud by default using the existing readback preference, and the composer exposes microphone and readback controls.
- Start Page Help keeps a full dialogue history for the onboarding session, supports microphone input, reads replies aloud by default, and keeps a manual Listen control on AI replies.
- The onboarding voice controls use the standard RPG Your Way readback identity instead of the obsolete Ithamir label.
- Step 4 is simplified to the nameplate "The naming of the names" with only the two input placeholders visible; accessible labels remain available to screen readers.
