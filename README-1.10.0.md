# RPG Your Way 1.10.0

Sitewide accessibility foundation and WCAG 2.2 AA readiness pass.

- Establishes **WCAG 2.2 Level AA** as the accessibility target for RPG Your Way pages and complete flows that the site controls.
- Adds a public **Accessibility** page and an engineering accessibility standard/checklist.
- Adds release-time accessibility regression checks for page language, skip navigation, image alternatives, dialog naming, keyboard order, pointer-only containers, focus treatment, reduced motion, forced colors, minimum target sizing, and core palette contrast.
- Strengthens visible keyboard focus with a two-tone focus ring that remains legible on both light and dark site surfaces.
- Adds better focus management to Start dialogs, account deletion, and responsive Play-panel changes.
- Improves headings, current-page navigation state, form descriptions, validation state, grouped controls, live status regions, and conversational announcements for screen-reader users.
- Keeps non-drag controls available for Play character reordering and removes drag-only wording from the character card's accessible name.
- Improves high-contrast/forced-colors and reduced-motion handling.
- Adds an **Accessibility** link to the site footer and an explicit accessibility feedback route.
- Advances the application release line from **1.9.4** to **1.10.0**.

This release creates a strong code-level accessibility baseline, but it deliberately does **not** claim independent certification. Final conformance also requires manual testing of the deployed site with keyboard navigation, zoom/reflow, high-contrast modes, and real screen-reader/browser combinations.
