# RPG Your Way 1.8.1

Start-page first visual correction pass. The page now begins with a three-control toolbar: a forest-green **Choose the game rules** accordion showing **D&D 5.5e · Default**, plus pale **I need help with all of this** and **Change age settings** controls. The rules accordion contains the five built-in rulesets and identifies the fixed setting as **The Uncharted Realms**. D&D 5.5e is selected automatically, so a default player can continue without opening the rules accordion.

The Start palette now favors olive rather than mint on secondary onboarding surfaces. This release also removes the accidental 1.8.0 `#00ff00` override, restoring the established RPG Your Way hot/accent green `#c1dc4d` sitewide.
