# RPG Your Way 1.11.4

Party-management and landing-page QA release.

- Character records now lead with the **name used in play** instead of displaying both that name and the underlying full record name together in the header.
- Adds **Remove from party** to character records. Removal keeps campaign history intact, clears stale initiative/level-up references, and preserves a valid party leader. The last active character cannot be removed until a replacement is added.
- Active multiplayer rosters now mirror coordinator party removals as well as additions, releasing any removed-character claims cleanly.
- Rounds the working buttons/controls that had drifted toward square corners on Play, character records, Start character-addition, and multiplayer UI.
- Expands the landing-page current-campaign display so the latest Game Master reply supplies the console text without pre-truncating it; the console itself handles the visible fill.
- Adds a top-of-landing-page forest-green **News** panel with a cream/brass town-crier-style nameplate and the two current headlines: **Reduction in prices, yay!** and **Multiplayer is now live.**
- Advances the release from **1.11.3** to **1.11.4**.
