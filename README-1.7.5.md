# RPG Your Way 1.7.5

Focused Play UI and voice cleanup after import-and-play QA.

- Voice input and readback are available to every signed-in Play customer; they remain part of RPG Your Way operating-cost coverage and do not separately debit the metered Play balance.
- Desktop Listen controls now have the mounted voice controls they require.
- Mobile composer uses two rows: the writing area gets the full first row, with microphone/readback and Send below.
- Desktop utility rails are more compact while gameplay text size is preserved, giving the conversation pane more room.
- Character-list scrollbar sits at the outer edge instead of wasting a gutter.
- Character reorder buttons move to the lower-right corner of character cards; desktop keeps hover/focus reveal and mobile keeps the controls visible.
- Mobile Character Record uses the available width, action buttons expand sensibly, the expanded identity/profile-picture editor can be scrolled to, and the heading is shortened to Character Record.
- Smart way to level uses readable forest-on-parchment contrast rather than lime-on-tan.
- No SQL migration and no package dependency change.
